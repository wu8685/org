# Org SDK Samples

选择一个 Sample，按照各自的 README 构建、发布并启动 Workflow。

| Sample | 运行后会看到什么 |
|---|---|
| [Hello](hello/README.md) | 两个步骤顺序执行，最终得到 `Hello, Codex!` |
| [Parallel confirmation](parallel-confirmation/README.md) | Workflow 先显示 `waiting-for-user`，确认后并行执行两个分支 |
| [Dynamic decision](dynamic-decision/README.md) | 执行选中的分支，另一个分支显示 `skipped` |

第一次运行建议从 Hello 开始。开始前先完成[本地快速上手](../docs/user/getting-started.md)中的环境启动步骤。

准备开发自己的项目时，使用专门的 [Worker Starter 教程](../docs/user/create-your-worker.md)。Samples 只展示对应的 Workflow 能力。
